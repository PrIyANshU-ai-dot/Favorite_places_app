# 📍 Favorite Places App

A beautiful, fully responsive Flutter application that allows users to mark, save, and revisit their favorite places — complete with geolocation, image capture, and map preview functionality. This app is built with clean architecture and intuitive UI principles, offering seamless interaction with device features.

---

## 🚀 Features

- 📌 **Add Favorite Places**
  - Capture a title and image.
  - Automatically fetch geolocation or select location manually via map.
- 🗺️ **Interactive Maps**
  - Visualize saved places with real-time Google Maps integration.
- 📷 **Camera & Gallery Support**
  - Take photos or choose from the gallery for custom place images.
- 🧭 **Device Location Access**
  - Leverage device GPS to automatically tag places.
- 💾 **Local Storage**
  - Offline-first experience using SQLite for persistent data.
- 📱 **Clean, Responsive UI**
  - Fully adaptable layout across devices with modern Material 3 styling.

---

## 🛠️ Tech Stack

- **Flutter** (latest stable version)
- **Dart**
- **SQLite** – For local database storage
- **Google Maps** – Map visualization
- **Location** package – Access to device location
- **Provider** – State management
- **Image Picker** – Capture or pick images
